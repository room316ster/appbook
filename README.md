# ระบบตรวจสอบวันนัดพิจารณาคดี (Smart Court Appoint Docket)
### พัฒนาสำหรับสำนักงานศาลยุติธรรม / ศาลแขวงอุบลราชธานี

ระบบดึงข้อมูลนัดพิจารณาคดีจาก API อัตโนมัติทุกวันลงใน Google Sheet (วันปัจจุบัน + 2 วันข้างหน้า รวม 3 วัน) และแสดงผลบนหน้าเว็บแอปพลิเคชันที่ทันสมัย รองรับทุกขนาดหน้าจอ (มือถือ, แท็บเล็ต, คอมพิวเตอร์, จอทีวีหน้าห้องพิจารณา) พร้อมระบบแยกสีประเภทคดี แยกสีช่วงเวลา ไอคอนสัญลักษณ์ และรองรับการส่งออกเป็นไฟล์ **APK สำหรับ Android**

## 📁 โครงสร้างไฟล์ในโปรเจกต์

| ชื่อไฟล์ | คำอธิบาย |
| :--- | :--- |
| `Code.gs` | ซอร์สโค้ด Google Apps Script สำหรับใส่ใน Google Sheets จัดการซิงค์ API, ตั้งเวลาอัตโนมัติ (Trigger), จัดรูปแบบชีต และสร้าง Web App API (`doGet` / `doPost`) |
| `index.html` | เว็บแอปพลิเคชันหลักสำหรับนำไปใช้บน **GitHub Pages** หรือ Web Hosting แสดงผลตารางนัดพิจารณา ค้นหา กรองคดี สลับการ์ด/ตาราง โหมดมืด/สว่าง และอ่านเสียงประกาศนัดคดี |
| `manifest.json` | ไฟล์ PWA Web App Manifest กำหนดชื่อแอพ ไอคอน และธีมสี สำหรับติดตั้งลงมือถือ และแปลงเป็นไฟล์ APK |
| `sw.js` | Service Worker สำหรับช่วยบันทึกแคช (Caching) ให้ออนไลน์/ออฟไลน์รวดเร็ว |
| `icon-192.png`, `icon-512.png` | ไอคอนตราดุลพาห (ตาชั่งศาลยุติธรรม) ความละเอียดสูงสำหรับไอคอนแอพมือถือ |
| `local_sync.py` | สคริปต์ Python สำหรับรันบนเครื่องคอมพิวเตอร์ภายในเครือข่ายศาล (Intranet) เพื่อดึงข้อมูลจาก IP `10.33.88.11:8089` แล้วส่งขึ้น Google Sheet |
| `local_sync.bat` | ไฟล์ Double-Click รันการซิงค์ข้อมูลบน Windows ได้ทันทีในคลิกเดียว |

## 🎨 การจัดแบ่งสีประเภทคดีและช่วงเวลา

### 1. แยกตามประเภทคดี (Case Types)
* 🔴 **คดีอาญา (อ, อบ, อท):** แถบสีแดงกุหลาบ (`Crimson Accent`) พร้อมไอคอนโล่/ตาชั่ง
* 🔵 **คดีผู้บริโภค (ผบ, ผช):** แถบสีฟ้าคราม (`Sky Blue Accent`) พร้อมไอคอนเอกสารคดี
* 🟣 **คดีแพ่ง (พ, พณ):** แถบสีม่วงรอยัล (`Purple Accent`) พร้อมไอคอนค้อนศาล
* 🟢 **คดีจัดการพิเศษ / อื่นๆ:** แถบสีเขียวมรกต (`Teal Accent`) พร้อมไอคอนแท็ก

### 2. แยกตามช่วงเวลานัด (Time Slots)
* 🌅 **รอบเช้า (09:00 - 10:00 น.):** ป้ายสีทอง/ส้มอบอุ่น (`Amber/Gold Badge`) ไอคอนพระอาทิตย์ขึ้น
* 🌤️ **รอบบ่าย (13:00 น. เป็นต้นไป):** ป้ายสีฟ้าท้องฟ้า (`Azure Blue Badge`) ไอคอนท้องฟ้าช่วงบ่าย

### ขั้นตอนที่ 2: อัปโหลดขึ้น GitHub Pages
1. นำไฟล์ต่อไปนี้ขึ้น GitHub Repository ของคุณ:

2. ไปที่ **Settings** ของ Repository บน GitHub > เลือกหัวข้อ **Pages**
3. ในส่วน **Build and deployment > Branch** ให้เลือก `main` (หรือ `master`) โฟลเดอร์ `/ (root)` แล้วกด **Save**
4. รอประมาณ 1 นาที จะได้ลิงก์หน้าเว็บ เช่น:
   `https://<your-username>.github.io/<repo-name>/`
5. เปิดหน้าเว็บขึ้นมา คลิกไอคอนเฟือง ⚙️ (ตั้งค่า) แล้วนำ **URL เว็บแอป** จากขั้นตอนที่ 1 มาวาง แล้วกดบันทึก

### ขั้นตอนที่ 3: วิธีสร้างไฟล์ APK สำหรับ Android (ง่ายที่สุดใน 2 นาที)

มี 2 ช่องทางหลัก:

#### วิธี A: แปลงเป็นไฟล์ APK ผ่าน PWABuilder (ไม่ต้องเขียนโค้ด)
1. เข้าไปที่เว็บไซต์ **[https://www.pwabuilder.com](https://www.pwabuilder.com)**
2. วาง URL หน้าเว็บ GitHub Pages ของคุณลงในช่อง แล้วกด **Start**
3. ระบบจะตรวจสอบความสมบูรณ์ของ PWA (ซึ่งโปรเจกต์นี้รองรับ 100% ทั้ง Manifest, Service Worker และ Icons)
4. เลื่อนลงมาที่หัวข้อ **Android** แล้วกดปุ่ม **Package for Android / Generate APK**
5. เลือกดาวน์โหลดไฟล์ **`.apk`** หรือ Signed Bundle นำไปติดตั้งลงบนโทรศัพท์มือถือ Android ได้ทันที!

#### วิธี B: ติดตั้งลงบนมือถือโดยตรง (Web App PWA)
* **Android (Chrome):** เปิดเว็บ แล้วกดจุด 3 จุดมุมขวาบน > เลือก **"ติดตั้งแอพ" (Install App)** หรือ **"เพิ่มลงในหน้าจอหลัก"**
* **iOS / iPhone (Safari):** เปิดเว็บ แล้วกดปุ่ม Share (สี่เหลี่ยมลูกศรชี้ขึ้น) > เลือก **"เพิ่มลงในหน้าจอหลัก" (Add to Home Screen)**
* แอพจะถูกติดตั้งลงบนหน้าจอเหมือนแอพพลิเคชันทั่วไป เปิดใช้งานแบบ Full-screen โดยไม่มีแถบเบราว์เซอร์กวนใจ

## 🔒 ข้อแนะนำเรื่องเครือข่ายภายในศาล (IP: 10.33.88.11)

เนื่องจาก URL `http://10.33.88.11:8089/...` เป็น **Private IP Address ภายในเครือข่าย Intranet ของศาล**:
* หาก Google Cloud ไม่สามารถเชื่อมต่อเข้ามายัง IP ภายในของศาลได้โดยตรง:
  1. ให้เปิดใช้งานสคริปต์ [`local_sync.py`](file:///d:/appscript/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%E0%B8%95%E0%B8%A3%E0%B8%A7%E0%B8%88%E0%B8%AA%E0%B8%AD%E0%B8%9A%E0%B8%A7%E0%B8%B1%E0%B8%99%E0%B8%99%E0%B8%B1%E0%B8%94%E0%B8%9E%E0%B8%B4%E0%B8%88%E0%B8%B2%E0%B8%A3%E0%B8%93%E0%B8%B2appbook/local_sync.py) บนคอมพิวเตอร์เครื่องใดก็ได้ที่เชื่อมต่อ Wi-Fi หรือสาย LAN ภายในศาล
  2. ใส่ `APPS_SCRIPT_WEBAPP_URL` ในไฟล์ `local_sync.py`
  3. สามารถคลิกที่ [`local_sync.bat`](file:///d:/appscript/%E0%B9%82%E0%B8%9B%E0%B8%A3%E0%B9%81%E0%B8%81%E0%B8%A3%E0%B8%A1%E0%B8%95%E0%B8%A3%E0%B8%A7%E0%B8%88%E0%B8%AA%E0%B8%AD%E0%B8%9A%E0%B8%A7%E0%B8%B1%E0%B8%99%E0%B8%99%E0%B8%B1%E0%B8%94%E0%B8%9E%E0%B8%B4%E0%B8%88%E0%B8%B2%E0%B8%A3%E0%B8%93%E0%B8%B2appbook/local_sync.bat) เพื่อดึงข้อมูลแล้วส่งขึ้น Google Sheet ได้ทันที
  4. หรือตั้งเวลาบน **Windows Task Scheduler** ให้สั่งรัน `local_sync.bat` ทุกเช้าเวลา 06:30 น. ข้อมูลบน Google Sheet และหน้าเว็บ GitHub Pages จะอัปเดตเป็นปัจจุบันโดยอัตโนมัติ

## ✨ สรุปฟีเจอร์เด่นบนหน้าเว็บ
1. **แถบเลือกวัน 3 วัน:** วันนี้, พรุ่งนี้, วันมะรืน, ทั้งหมด พร้อมตัวเลขจำนวนคดี
2. **ระบบค้นหาแบบ Real-time:** ค้นหาได้ทั้งเลขคดีดำ, โจทก์, จำเลย, ห้องพิจารณา, สาเหตุนัด
3. **ตัวกรองคดี:** กรองแยกตามห้องพิจารณา, แยกตามประเภทคดี (อาญา/ผู้บริโภค/แพ่ง), แยกตามเวลา
4. **โหมดการแสดงผล 2 แบบ:** สลับระหว่างแบบการ์ด (Card View) และแบบตารางประกาศศาล (Table Docket View)
5. **ฟังเสียงอ่านประกาศนัด:** มีปุ่มกดอ่านรายละเอียดคดีด้วยเสียงสังเคราะห์ภาษาไทย (Thai Text-to-Speech)
6. **ปุ่มพิมพ์ใบตารางนัด:** จัดรูปแบบสะอาดตาพร้อมพิมพ์แจกหรือติดประกาศหน้าห้องพิจารณาคดี
7. **ธีม Dark Mode / Light Mode:** สลับโหมดมืด-สว่างเพื่อความสบายตา

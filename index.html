วิธีที่ 1: ติดตั้งลงมือถือทันที (ไม่ต้องลง APK - แนะนำที่สุด)

เปิดเว็บนี้บนมือถือ Chrome / Safari แล้วกดปุ่ม "เพิ่มลงในหน้าจอหลัก" (Add to Home Screen) แอพจะถูกติดตั้งลงมือถือพร้อมไอคอนตราศาลทันที ใช้งานได้เสมือนแอพแท้

วิธีที่ 2: แปลงเป็นไฟล์ .APK ฟรีผ่าน PWABuilder (ใน 2 นาที)
  1. นำเว็บนี้อัปขึ้น GitHub Pages จะได้ URL เช่น https://yourname.github.io/...
  2. เข้าไปที่เว็บ www.pwabuilder.com
  3. วาง URL เว็บของคุณ แล้วกด Start
  4. กดปุ่ม Build APK / Package for Android เพื่อดาวน์โหลดไฟล์ .apk ไปติดตั้งบนมือถือ Android ได้ทันที!
